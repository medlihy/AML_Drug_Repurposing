# AML Drug Repurposing

This repository contains the R analysis code associated with the manuscript *Integrative Transcriptomic Drug Repurposing Identifies Albendazole and Mebendazole as Anti-Leukemic Candidates in Acute Myeloid Leukemia*.

The code covers bulk and single-cell transcriptomics, bulk WGCNA and single-cell hdWGCNA, cell composition, CytoTRACE2, CellChat, pseudobulk differential expression, multi-layer AML core-signature construction, perturbational drug prioritization, and directional transcriptional reversal.

## Analysis workflow

1. `01_Bulk_DEG_limma.R` processes GSE114868 and performs limma differential expression.
2. `02_Bulk_WGCNA.R` builds the signed bulk co-expression network and exports module membership, gene significance, hub-gene, module–trait, and DEG-integration results.
3. `03_Bulk_WGCNA_Replot.R` and `scripts/auxiliary/Bulk_WGCNA_SoftPower_Replot.R` replot existing WGCNA outputs without rebuilding the network.
4. `04_scRNA_Preprocessing.R` contains the GSE130756 preprocessing, QC, decontamination, doublet, Harmony, and clustering workflow.
5. `05_scRNA_Annotation.R` calculates cluster markers and applies an externally reviewed cluster-to-cell-type mapping.
6. Scripts 06–10 consume an annotated Seurat object for cell proportions, hdWGCNA, CytoTRACE2, pseudobulk DEG, and CellChat.
7. `11_Core_Gene_Integration_Heatmap_UpSet.R` generates the strict AML core signature by integrating bulk DEG, pseudobulk DEG, bulk WGCNA, hdWGCNA, expression prevalence, and cross-platform direction consistency. It also performs 96 threshold-sensitivity combinations and produces UpSet/evidence/circular heatmap figures.
8. Scripts 12–13 perform perturbational drug prioritization and drug RNA-seq directional reversal analysis.

## Repository structure

- `scripts/01_Bulk_DEG_limma.R`: GSE114868 preprocessing, QC, gene summarization, and limma analysis.
- `scripts/02_Bulk_WGCNA.R`: complete bulk WGCNA network construction and DEG integration.
- `scripts/03_Bulk_WGCNA_Replot.R`: module–trait and soft-power replotting from script 02 outputs.
- `scripts/04_scRNA_Preprocessing.R`: single-cell preprocessing and clustering workflow; unresolved workflow branches are documented below.
- `scripts/05_scRNA_Annotation.R`: marker analysis and cell-type annotation workflow.
- `scripts/06_scRNA_Cell_Proportions.R`: cell-composition summaries and figures.
- `scripts/07_scRNA_hdWGCNA.R`: hdWGCNA and module/hub-gene export.
- `scripts/08_scRNA_CytoTRACE2.R`: CytoTRACE2 differentiation-potency analysis.
- `scripts/09_scRNA_Pseudobulk_DEG.R`: sample-level aggregation and limma-voom DEG analysis.
- `scripts/10_scRNA_CellChat.R`: one combined CellChat model across all included AML and Normal cells, grouped by the 21 cell types. This is not an AML-versus-Normal differential CellChat comparison.
- `scripts/11_Core_Gene_Integration_Heatmap_UpSet.R`: strict core-gene generation, sensitivity analysis, and visualization.
- `scripts/12_Drug_Prioritization.R`: cMAP/L1000FWD perturbational scoring and prioritization.
- `scripts/13_Core_Gene_Reversal.R`: DESeq2 drug-response modeling and weighted core-signature reversal.
- `scripts/auxiliary/Bulk_WGCNA_SoftPower_Replot.R`: optional clean soft-power figure export.
- `config/paths_example.R`: portable path template.
- `docs/Dependencies.md`: static package inventory.
- `docs/Input_Output_Requirements.md`: input/output and dependency contracts.
- `docs/Static_Audit_Notes.md`: important unresolved static findings.

## Data requirements

The scripts refer to GSE114868 and GSE130756. Data are not redistributed. Users must supply the exact series-matrix, platform-annotation, single-cell count-table, annotation, perturbational-screen, and drug RNA-seq files described in `docs/Input_Output_Requirements.md`.

The bulk WGCNA gene-level table required by the core-signature script is now generated by script 02 at `05_hub_genes/01_gene_module_membership_GS_DEG.tsv`. The single-cell expression-prevalence input is still not generated by the supplied scripts unless compatible prevalence columns are already present in the pseudobulk DEG input.

## Software environment

The original R and package versions are not documented. No versions have been inferred. See `docs/Dependencies.md`. Several scripts are memory intensive and may require a Linux or high-memory environment.

## Execution guidance

Run scripts from the repository root. Copy `config/paths_example.R` to `config/paths.R` and edit paths, or set `AML_PATH_CONFIG` to an external configuration file. Local data, results, and `config/paths.R` are ignored by Git.

The numbering represents the evidence workflow, not a claim that the entire repository is currently executable without intervention. Static audit found unresolved objects and competing workflow branches in script 04, an annotation-object filename mismatch, a CytoTRACE2 placeholder, missing annotation helper files, and unverified experimental/input assumptions. Read `docs/Static_Audit_Notes.md` before execution.

No R analysis was executed while preparing this candidate repository. Dependencies were not installed, data were not downloaded, and the 62-gene result, WGCNA modules, CellChat pathways, drug rankings, and reversal scores were not recomputed or validated.
